Documentação da API - Artigos (Article)

Esta seção documenta os endpoints responsáveis pelo gerenciamento de artigos no sistema Jornal.

Endpoints de Artigos (Article)

POST /article

Cria um novo artigo no banco de dados.

Requisição:
{
    "SubCategoryId": 1,
    "WriterID": 3,
    "ReviewID": null,
    "Title": "Novo Artigo de Tecnologia",
    "Slug": "novo-artigo-de-tecnologia",
    "Post": {
        "Type": "doc",
        "Content": [
            { "Type": "paragraph", "Text": "Conteúdo do artigo..." }
        ]
    },
    "Data": "2025-10-06T00:00:00Z",
    "Comments": []
}

Resposta:
"Sucessfull"

GET /articles

Retorna todos os artigos cadastrados no sistema.

Resposta:
[
    {
        "Id": 1,
        "SubCategoryId": 1,
        "WriterID": 3,
        "ReviewID": null,
        "Title": "Primeiro Artigo",
        "Slug": "primeiro-artigo",
        "Post": {
            "Type": "doc",
            "Content": []
        },
        "Data": "2025-09-29T00:00:00Z",
        "Comments": []
    }
]

GET /article/{id}

Retorna um artigo específico com base no ID informado.

Parâmetros:
id (int) - ID do artigo

Resposta:
{
    "Id": 1,
    "SubCategoryId": 1,
    "WriterID": 3,
    "ReviewID": null,
    "Title": "Primeiro Artigo",
    "Slug": "primeiro-artigo",
    "Post": {
        "Type": "doc",
        "Content": [
            { "Type": "paragraph", "Text": "Conteúdo do artigo" }
        ]
    },
    "Data": "2025-09-29T00:00:00Z",
    "Comments": []
}

Parâmetros:

Resposta:

Modelo de Dados - Article

Campo Tipo Descrição
Id int Identificador único do artigo.
SubCategoryId int ID da subcategoria à qual o artigo pertence.
WriterID int? ID do autor (opcional).
ReviewID int? ID do revisor (opcional).
Title string Título do artigo.
Slug string Identificador usado em URLs amigáveis.
Post Document Estrutura de conteúdo do artigo (texto, imagens, etc.).
Data DateTime Data de publicação do artigo.
Comments List<Message> Lista de comentários associados ao artigo.
