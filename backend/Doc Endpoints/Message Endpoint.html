Documentação da API - Mensagens (MessageEndpoint)

Esta documentação descreve os endpoints responsáveis pelo gerenciamento de mensagens (comentários) de artigos no sistema Jornal.

Endpoints de Mensagem

POST /message

Cria uma nova mensagem vinculada a um artigo e a um usuário existente.

Requisição:
{
    "UserId": 1,
    "ArticleId": 5,
    "Text": "Ótimo artigo, parabéns!"
}

Resposta:
{
    "Id": 12,
    "ArticleId": 5,
    "UserId": 1,
    "Text": "Ótimo artigo, parabéns!",
    "CreatedAt": "2025-10-08T00:00:00Z"
}

GET /messages

Retorna todas as mensagens cadastradas no sistema.

Resposta:
[
    {
        "Id": 12,
        "ArticleId": 5,
        "UserId": 1,
        "Text": "Ótimo artigo, parabéns!",
        "CreatedAt": "2025-10-08T00:00:00Z"
    },
    {
        "Id": 13,
        "ArticleId": 6,
        "UserId": 2,
        "Text": "Muito interessante!",
        "CreatedAt": "2025-10-08T00:00:00Z"
    }
]

GET /message/{id}

Retorna uma mensagem específica com base no ID informado.

Parâmetros:
id (int)

Resposta:
{
    "Id": 12,
    "ArticleId": 5,
    "UserId": 1,
    "Text": "Ótimo artigo, parabéns!",
    "CreatedAt": "2025-10-08T00:00:00Z"
}

PUT /message/{id}

Atualiza o texto de uma mensagem existente.

Requisição:
{
    "Text": "Comentário atualizado!"
}

Resposta:
{
    "Id": 12,
    "ArticleId": 5,
    "UserId": 1,
    "Text": "Comentário atualizado!",
    "CreatedAt": "2025-10-08T00:00:00Z"
}

DELETE /message/{id}

Remove uma mensagem com base no ID informado.

Parâmetros:
id (int)

Resposta:
"Message 12 deleted"

Modelo de Dados - Message

CampoTipoDescrição
IdintIdentificador único da mensagem.
ArticleIdintID do artigo ao qual a mensagem está vinculada.
UserIdintID do usuário autor da mensagem.
TextstringConteúdo textual da mensagem.
CreatedAtDateTimeData e hora de criação da mensagem.

Observações

  • Uma mensagem sempre pertence a um usuário e a um artigo.
  • O campo Text é obrigatório em todas as operações de criação e atualização.
  • O endpoint PUT atualiza apenas o texto da mensagem.
  • O endpoint GET /messages retorna todas as mensagens, sem paginação por padrão.
