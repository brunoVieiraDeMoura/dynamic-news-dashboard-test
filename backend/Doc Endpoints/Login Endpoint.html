Documentação da API - Login (LoginEndpoint)

Este endpoint é responsável pela autenticação de usuários no sistema Jornal. Ele valida as credenciais enviadas, gera um token JWT e retorna ao cliente para autenticação nas próximas requisições.

Endpoint de Login

POST /login

Autentica um usuário com base em seu e-mail e senha. Retorna um token JWT válido por 24 horas.

Requisição:
{
    "Email": "joao@example.com",
    "Password": "123456"
}

Resposta:
{
    "Token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}

Processo de Autenticação

  1. O sistema busca o usuário no banco de dados com base no Email informado.
  2. Valida a senha utilizando BCrypt.Verify.
  3. Gera um token JWT com as seguintes informações (Claims):
    • Name: Email do usuário.
    • Role: Permissão do usuário (ex: user, admin, writer).
  4. Assina o token usando a chave configurada em JwtSettings.Key.
  5. Retorna o token no corpo da resposta.

Configuração JWT (JwtSettings)

{
    "Jwt": {
        "Key": "sua_chave_supersecreta",
        "Issuer": "JornalAPI",
        "Audience": "JornalClients"
    }
}

Modelo de Dados - LoginDto

CampoTipoDescrição
EmailstringEmail cadastrado do usuário.
PasswordstringSenha do usuário.

Exemplo de Token JWT Decodificado

{
  "name": "joao@example.com",
  "role": "user",
  "exp": 1739057292
}

Erros Possíveis

CódigoDescrição
401 UnauthorizedUsuário não encontrado ou senha inválida.
400 Bad RequestDados inválidos na requisição.

Observações

  • O token retornado deve ser incluído no cabeçalho das requisições autenticadas:
    • Authorization: Bearer {token}
  • O token expira após 24 horas.
  • Utiliza o algoritmo HMAC SHA-256 para assinatura.
