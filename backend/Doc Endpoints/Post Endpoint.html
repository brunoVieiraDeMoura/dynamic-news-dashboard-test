Documentação da API - Posts (PostEndpoint)

Esta seção documenta os endpoints responsáveis pelo gerenciamento de posts no sistema Jornal.

Endpoints de Post

POST /post

Cria um novo post associado a um usuário existente.

Requisição:
{
    "UserId": 1,
    "Title": "Meu Primeiro Post",
    "Text": "Este é o conteúdo do post."
}

Resposta:
{
    "Id": 10,
    "Date": "2025-10-08T00:00:00Z",
    "UserId": 1,
    "Title": "Meu Primeiro Post",
    "Text": "Este é o conteúdo do post.",
    "UserName": "João Silva"
}

GET /posts

Retorna todos os posts cadastrados no sistema, incluindo o nome do usuário autor de cada post.

Resposta:
[
    {
        "Id": 10,
        "Date": "2025-10-08T00:00:00Z",
        "UserId": 1,
        "Title": "Meu Primeiro Post",
        "Text": "Este é o conteúdo do post.",
        "UserName": "João Silva"
    },
    {
        "Id": 11,
        "Date": "2025-10-08T00:00:00Z",
        "UserId": 2,
        "Title": "Outro Post",
        "Text": "Conteúdo de exemplo.",
        "UserName": "Maria Souza"
    }
]

GET /post/{id}

Retorna um post específico com base no ID informado.

Parâmetros:
id (int)

Resposta:
{
    "Id": 10,
    "Date": "2025-10-08T00:00:00Z",
    "UserId": 1,
    "Title": "Meu Primeiro Post",
    "Text": "Este é o conteúdo do post.",
    "UserName": "João Silva"
}

PUT /post/{id}

Atualiza os dados de um post existente.

Requisição:
{
    "Title": "Post Atualizado",
    "Text": "Conteúdo do post foi alterado."
}

Resposta:
{
    "Id": 10,
    "Date": "2025-10-08T00:00:00Z",
    "UserId": 1,
    "Title": "Post Atualizado",
    "Text": "Conteúdo do post foi alterado.",
    "UserName": "João Silva"
}

DELETE /post/{id}

Remove um post com base no ID informado.

Parâmetros:
id (int)

Resposta:
"Post 10 deleted"

Modelo de Dados - Post

CampoTipoDescrição
IdintIdentificador único do post.
DateDateTimeData de criação do post.
UserIdintID do usuário autor do post.
TitlestringTítulo do post.
TextstringConteúdo textual do post.
UserUserReferência ao usuário autor (relacionamento).

Modelo de Dados - PostDto

{
    "Id": 10,
    "Date": "2025-10-08T00:00:00Z",
    "UserId": 1,
    "Title": "Exemplo de Post",
    "Text": "Conteúdo de exemplo.",
    "UserName": "João Silva"
}

Modelo Relacionado - User

{
    "Id": 1,
    "Name": "João Silva",
    "Email": "joao@example.com",
    "Role": "user"
}

Observações

  • Todos os posts estão associados a um usuário existente (UserId deve ser válido).
  • As respostas utilizam o modelo PostDto para incluir o campo UserName.
  • O endpoint PUT atualiza apenas os campos Title e Text.
