Documentação da API - Categorias (CategoryEndpoint)

Esta seção documenta os endpoints responsáveis pelo gerenciamento de categorias no sistema Jornal.

Endpoints de Categoria

POST /category

Cria uma nova categoria no sistema.

Requisição:
{
    "Name": "Tecnologia",
    "Slug": "tecnologia"
}

Resposta:
{
    "Id": 1,
    "Name": "Tecnologia",
    "Slug": "tecnologia",
    "SubCategories": [],
    "Date": "2025-10-08T00:00:00Z"
}

GET /categorys

Retorna todas as categorias cadastradas, incluindo suas subcategorias.

Resposta:
[
    {
        "Id": 1,
        "Name": "Tecnologia",
        "Slug": "tecnologia",
        "Date": "2025-10-08T00:00:00Z",
        "SubCategories": [
            {
                "Id": 1,
                "CategoryId": 1,
                "Name": "IA e Robótica",
                "Slug": "ia-robotica",
                "Date": "2025-10-08T00:00:00Z"
            }
        ]
    }
]

GET /category/{id}

Retorna uma categoria específica com base no ID informado, incluindo suas subcategorias.

Parâmetros:
id (int)

Resposta:
{
    "Id": 1,
    "Name": "Tecnologia",
    "Slug": "tecnologia",
    "Date": "2025-10-08T00:00:00Z",
    "SubCategories": [
        {
            "Id": 1,
            "CategoryId": 1,
            "Name": "IA e Robótica",
            "Slug": "ia-robotica"
        }
    ]
}

PUT /category/{id}

Atualiza os dados de uma categoria existente.

Requisição:
{
    "Name": "Tecnologia Atualizada",
    "Slug": "tecnologia-atualizada"
}

Resposta:
{
    "Id": 1,
    "Name": "Tecnologia Atualizada",
    "Slug": "tecnologia-atualizada",
    "Date": "2025-10-08T00:00:00Z"
}

DELETE /category/{id}

Remove uma categoria existente com base no ID informado.

Parâmetros:
id (int)

Resposta:
"Category 1 Deleted"

Modelo de Dados - Category

CampoTipoDescrição
IdintIdentificador único da categoria.
NamestringNome da categoria.
SlugstringIdentificador amigável usado na URL.
DateDateTimeData de criação da categoria.
SubCategoriesList<SubCategory>Lista de subcategorias associadas à categoria.

Modelo de Dados - CategoryDto

{
    "Id": 1,
    "Name": "Tecnologia",
    "Slug": "tecnologia",
    "Date": "2025-10-08T00:00:00Z",
    "SubCategories": []
}

Modelo Relacionado - SubCategory

{
    "Id": 1,
    "CategoryId": 1,
    "Name": "IA e Robótica",
    "Slug": "ia-robotica",
    "Date": "2025-10-08T00:00:00Z"
}

Observações

  • O campo Slug é usado para URLs amigáveis.
  • Cada categoria pode possuir múltiplas subcategorias associadas.
  • O endpoint PUT permite atualizar apenas Name e Slug.
  • O endpoint GET /categorys retorna todas as categorias com suas subcategorias aninhadas.
