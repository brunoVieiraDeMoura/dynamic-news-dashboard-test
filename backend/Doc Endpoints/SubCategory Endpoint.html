Documentação da API - SubCategorias (SubCategoryEndpoint)

Esta documentação descreve os endpoints responsáveis pelo gerenciamento de subcategorias dentro do sistema Jornal.

Endpoints de SubCategoria

POST /subcategory

Cria uma nova subcategoria vinculada a uma categoria existente.

Requisição:
{
    "CategoryId": 1,
    "Name": "Inteligência Artificial",
    "Slug": "inteligencia-artificial"
}

Resposta:
{
    "Id": 5,
    "CategoryId": 1,
    "Name": "Inteligência Artificial",
    "Slug": "inteligencia-artificial",
    "Date": "2025-10-08T00:00:00Z"
}

GET /subcategorys

Retorna todas as subcategorias registradas no sistema, incluindo as categorias às quais pertencem.

Resposta:
[
    {
        "Id": 5,
        "CategoryId": 1,
        "Name": "Inteligência Artificial",
        "Slug": "inteligencia-artificial",
        "Date": "2025-10-08T00:00:00Z"
    },
    {
        "Id": 6,
        "CategoryId": 2,
        "Name": "Cinema",
        "Slug": "cinema",
        "Date": "2025-10-08T00:00:00Z"
    }
]

GET /subcategory/{id}

Retorna uma subcategoria específica com base no ID informado (do campo CategoryId).

Parâmetros:
id (int)

Resposta:
{
    "Id": 5,
    "CategoryId": 1,
    "Name": "Inteligência Artificial",
    "Slug": "inteligencia-artificial",
    "Date": "2025-10-08T00:00:00Z"
}

PUT /subcategory/{id}

Atualiza o nome e/ou slug de uma subcategoria existente.

Requisição:
{
    "Name": "IA Atualizada",
    "Slug": "ia-atualizada"
}

Resposta:
{
    "Id": 5,
    "CategoryId": 1,
    "Name": "IA Atualizada",
    "Slug": "ia-atualizada",
    "Date": "2025-10-08T00:00:00Z"
}

DELETE /subcategory/{id}

Remove uma subcategoria do banco de dados.

Parâmetros:
id (int)

Resposta:
"SubCategory Id:5 Deleted"

Modelo de Dados - SubCategory

CampoTipoDescrição
IdintIdentificador único da subcategoria.
CategoryIdintID da categoria à qual pertence.
NamestringNome da subcategoria.
SlugstringIdentificador amigável usado em URLs.
DateDateTimeData de criação da subcategoria.

Modelo de Dados - SubCategoryDto

{
    "Id": 5,
    "CategoryId": 1,
    "Name": "Inteligência Artificial",
    "Slug": "inteligencia-artificial",
    "Date": "2025-10-08T00:00:00Z"
}

Modelo Relacionado - Category

{
    "Id": 1,
    "Name": "Tecnologia",
    "Slug": "tecnologia",
    "Date": "2025-10-08T00:00:00Z"
}

Observações

  • O campo CategoryId deve apontar para uma categoria existente.
  • O endpoint PUT atualiza apenas os campos Name e Slug.
  • O endpoint GET /subcategorys lista todas as subcategorias com suas respectivas categorias.
  • Os slugs devem ser únicos dentro da mesma categoria.
