Documentação da API - Usuários (UserEndpoint)

Esta seção documenta os endpoints responsáveis pelo gerenciamento de usuários no sistema Jornal.

Endpoints de Usuário

POST /user

Cria um novo usuário com base nas informações fornecidas no corpo da requisição.

Requisição:
{
    "Name": "João Silva",
    "Email": "joao@example.com",
    "Password": "123456"
}

Resposta:
"Usuario criado com sucesso!"

POST /user/google

Autentica ou registra um usuário através do login com Google.

Requisição:
{
    "IdToken": "GOOGLE_ID_TOKEN"
}

Resposta:
"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." (JWT Token)

GET /users

Retorna uma lista de todos os usuários cadastrados no sistema.

Resposta:
[
    {
        "Id": 1,
        "Date": "2025-10-08T00:00:00Z",
        "Name": "João Silva",
        "Email": "joao@example.com",
        "Password": "hash_bcrypt",
        "Role": "user"
    }
]

GET /user/{id}

Retorna as informações de um usuário específico, incluindo seus posts.

Parâmetros:
id (int)

Resposta:
{
    "Id": 1,
    "Date": "2025-10-08T00:00:00Z",
    "Name": "João Silva",
    "Email": "joao@example.com",
    "Role": "user",
    "Posts": [
        { "Id": 10, "Title": "Meu primeiro post", "Slug": "meu-primeiro-post" }
    ]
}

PUT /user/{id}

Atualiza as informações de um usuário existente.

Requisição:
{
    "Name": "João Atualizado",
    "Email": "joao.novo@example.com",
    "Password": "novaSenha",
    "Role": "admin"
}

Resposta:
{
    "Id": 1,
    "Name": "João Atualizado",
    "Email": "joao.novo@example.com",
    "Role": "admin"
}

DELETE /user/{id}

Remove um usuário com base no ID informado.

Parâmetros:
id (int)

Resposta:
"User 1 deleted"

POST /user/me

Retorna as informações do usuário autenticado com base no token JWT presente no cabeçalho.

Headers:
Authorization: Bearer {token}

Resposta:
{
    "Id": 1,
    "Date": "2025-10-08T00:00:00Z",
    "Name": "João Silva",
    "Email": "joao@example.com",
    "Role": "user"
}

Modelo de Dados - User

CampoTipoDescrição
IdintIdentificador único do usuário.
NamestringNome completo do usuário.
EmailstringEmail utilizado para login.
PasswordstringSenha criptografada (BCrypt).
RolestringFunção do usuário no sistema (user, admin, writer, review).
DateDateTimeData de criação do usuário.
PostsList<Post>Lista de posts criados pelo usuário.
